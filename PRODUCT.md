# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Primary: Recruiters and hiring managers evaluating technical candidates for junior/entry-level positions. Secondary: Potential freelance clients seeking web development services.

## Product Purpose

Personal portfolio website to showcase Guilherme Buys' development skills, projects, and autodidactic journey. Success means converting visitors into interview opportunities or freelance leads.

## Positioning

Differentiated by a compelling autodidactic narrative — a developer who left technical school early due to exceeding the curriculum pace, now pursuing Computer Science at UniRitter. Combines full-stack web development (Next.js/TypeScript) with backend API development.

## Operating Context

Visitors arrive via direct links (resume, social media), search, or referrals. They scan quickly on desktop or mobile, evaluate technical competence through project examples, and decide whether to reach out. The site must load fast, look professional, and communicate capability within seconds.

## Capabilities and Constraints

- Static portfolio site (no auth, no CMS, no dynamic data)
- Next.js 16 + React 19 + Tailwind CSS 4 stack
- Deployed on Vercel (implied by create-next-app scaffold)
- Must work across desktop, tablet, and mobile viewports
- Profile photo hosted on GitHub avatars
- Resume PDF served from public directory

## Brand Commitments

- Name: Guilherme Buys / Buys Code
- Voice: Professional but approachable, confident without arrogance
- Personality: Curious, self-driven, technically capable
- Language: Portuguese (Brazilian)

## Product Principles

1. Lead with the autodidactic story — it's the most memorable differentiator
2. Show, don't tell — project examples speak louder than badge lists
3. Professional polish builds trust — every detail signals competence
4. Mobile-first — recruiters browse on phones between meetings
5. Fast and lightweight — no bloat, instant load, respect for visitor time
